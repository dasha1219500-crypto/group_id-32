## Просмотр Colab-ноутбука

В файле `LAB01_KTvD.ipynb` используются **интерактивные графики Plotly** и элементы управления. **GitHub показывает ноутбуки в статическом режиме**: интерактивные графики могут не отображаться или работать не полностью. Это ограничение предпросмотра GitHub, а не признак отсутствия графиков в исследовании.

Чтобы увидеть и проверить всё исследование:

1. Откройте [Google Colab](https://colab.research.google.com/).
2. Выберите **Файл → Открыть блокнот → GitHub** и найдите `LAB01_KTvD.ipynb` в репозитории (либо скачайте файл и загрузите его в Colab).
3. В Colab выберите **Среда выполнения → Выполнить все**.
4. Используйте интерактивные графики и переключатели непосредственно в Colab.

*Для первого запуска может потребоваться интернет-соединение, чтобы загрузить исходные данные и зависимости.*

## Запуск marimo

Для запуска нужен установленный **Python**. В терминале, находясь в папке с файлами проекта, выполните:

```bash
python -m pip install marimo numpy pandas scipy plotly
python -m marimo run Lab01_KTvD_MARIMO_.py
```

После запуска откройте адрес, который появится в терминале (обычно `http://localhost:2718`). Приложение позволяет менять параметры исследования и сразу видеть обновлённые результаты. Для остановки сервера нажмите `Ctrl + C` в терминале.

## Что исследуется

- **Газовые сенсоры:** предварительный анализ данных (EDA), распределения, характеристики случайных величин X, Y и Z, зависимости, выборочные оценки, модели генерации случайных значений и проверки.
- **Дополнительное исследование Diamonds:** анализ массы (`carat`) и цены (`price`), их зависимости, распределений и результатов моделирования.
- **Дизайнерская часть КТвД:** единая визуальная система, читаемые графики и единицы измерения, навигация, интерактивные элементы и представление результатов на сайте и в marimo.
